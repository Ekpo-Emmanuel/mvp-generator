# Card

The container for each demo on the page: an illustration zone on top, a title and one short paragraph below.

## Specs
- `panel` background, 1px `line-2` border, `radius-lg`, overflow hidden. No shadow.
- Illustration zone: `sunk` background, 300px tall, a `line` rule under it. White chips and tiles lift off it; the dark terminal panel (`term`) sits inside it.
- Body: `card-title` (Fraunces) then one paragraph in `ink-2`. At most one text link, which has a trailing arrow icon.
- Two cards sit side by side on desktop and stack on phones.
