# FaqRow

One question in the FAQ list. Rows are native disclosure elements in one exclusive group, so opening a row closes the others.

## Specs
- Question in the `sans` face at 18px (17px on phones), weight 500, with a plus mark drawn in `ink` (two 14px lines) on the right.
- Rows are divided by a `line` hairline. Padding 20px top and bottom.
- Answer text in `ink-2`; code in an answer uses `mono` on `sunk`.
- Keep answers to one or two sentences. Five rows at most.
