# Highlight

A hand-marked lime swipe behind the key phrase of the one headline per page ("getting somewhere."). It is the page's one flourish.

## Specs
- A slightly uneven lime shape behind the text, drawn per line so it follows a wrapped phrase. Text on it is `on-accent`.
- Motion: the headline shows plain, then the highlight sweeps in from the left over about 1s. It plays once.
- Visitors who prefer reduced motion see the finished highlight.
- On a lime band the same swipe is white.
- Use once per page. Never on body text.
