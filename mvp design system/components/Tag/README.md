# Tag

A small outlined pill that carries one fact about the project, such as "Open source | Free to make something". It links to the source.

## Specs
- Height 26px (24px on phones), `radius-pill`, `line-2` border on `panel`.
- Left: the GitHub mark (13px). Then a bold label in `ink`, a 1px divider, and supporting text in `mute`. Text is 12px.
- Hover: border goes to `ink`, background to `accent-soft`.
- Use once per page, above the headline. Not a button; do not use it for actions.
