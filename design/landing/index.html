    A few things you might be wondering.

    Is it really free?
    Yes. mvp is open source under the MIT licence. No account, no subscription.
    What’s inside the download?
    A project folder for the framework you picked, with auth, database and styling connected, plus a .env.example listing the keys you’ll need.
    What do I need to do after downloading?
    Unzip, copy .env.example to .env, add your keys, then npm install and npm run dev.
    Can I change the code later?
    All of it. It’s plain code in your folder — nothing to eject from.
    Who makes it?
    mvp is open source and maintained by @Ekpo-Emmanuel. Read the code, open an issue, or send a pull request on GitHub.
    Do I need an account?
    No. The project is generated in your browser.
